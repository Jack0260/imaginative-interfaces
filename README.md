# Dream Weaver UI

Build a prototype system that takes imaginative, dream-like natural language descriptions of UIs (e.g., "a glowing dashboard that breathes") and generates working HTML/CSS/JS prototypes. Include semantic parsing, design synthesis, and a rendering engine.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://imaginative-interfaces.lovable.app
